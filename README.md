# Next Arrival for AltStore Classic

Install Next Arrival by adding this source to AltStore Classic:

```text
https://raw.githubusercontent.com/gmoran1016/next-arrival-altstore/main/source.json
```

In AltStore, open **Sources**, choose **Add Source**, and paste the URL above. Then install
**Next Arrival** from the source. Install or refresh it through AltServer on your computer;
AltServer signs the app and its widget extension with your Apple account. A free Personal Team
installation expires after seven days and must be refreshed through AltServer.

This repository contains only the AltStore listing and icon. The installable IPA is attached to
each [GitHub Release](https://github.com/gmoran1016/next-arrival-altstore/releases).

For AltStore Classic source format details, see the [AltStore source documentation](https://faq.altstore.io/developers/make-a-source).
